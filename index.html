// Projects

ACO Pathfinding & Algorithm Analysis

An interactive Python pathfinding simulator built around Ant Colony Optimization (ACO), exploring probabilistic decision-making, graph theory, and heuristic search. Compares ACO against Breadth-First Search (BFS) and A* across grid-based environments.

Implemented pheromone reinforcement and evaporation, probabilistic path selection, and heuristic-based search. Developed an interactive Pygame visualizer displaying artificial ants, obstacles, explored nodes, pheromone trails, and optimal paths.

Built a reproducible benchmarking suite evaluating algorithm performance across 20 deterministic grid configurations. In the documented baseline run, ACO achieved a 75% optimality hit rate with an average optimality gap of 1.31% against BFS at 300 generations.

Python | Pygame | Ant Colony Optimization | BFS | A* | Graph Theory | Algorithms | Benchmarking | Unit Testing

PlayTracker

A full-stack NBA player statistics application built with Java and Spring Boot. The application provides a REST API for searching players, teams, and individual player statistics.

Implemented a layered architecture separating REST controllers, business logic, and data access. Player records can be created, updated, searched, soft-deleted, and restored through the API.

Built around a relational database with a dedicated DAO layer, service layer, exception handling, and frontend pages for interacting with player and statistical data.

Java | Spring Boot | REST API | SQL | MariaDB | JavaScript | HTML | CSS | DAO | OOP

Football Analytics Engine

A Python-based football analytics pipeline built using event-level StatsBomb data from the 2015/16 Premier League. The project analyzes shot volume, expected goals (xG), finishing efficiency, and overall team performance.

Processed event data across all 380 league matches using Pandas, calculated team-level attacking metrics, and compared expected goals against actual results to identify trends in shot quality and finishing.

Built an interactive Streamlit dashboard for exploring team performance, league standings, goals scored, and expected goals alongside the underlying analytical dataset.

Python | Pandas | StatsBomb | Streamlit | Matplotlib | Data Analysis | Data Visualization

Sudoku Solver

An interactive Sudoku solver and puzzle generator built with Python and Tkinter. The application uses backtracking with Minimum Remaining Values (MRV) optimization to efficiently solve Sudoku puzzles.

Implemented puzzle validation, unique-solution verification, randomized puzzle generation, and difficulty-based generation. The solver also tracks search attempts, backtracks, and execution time to analyze solving performance.

Built an interactive desktop interface with editable Sudoku grids, difficulty selection, real-time input validation, invalid-move feedback, and visual distinction between puzzle clues and solver-generated values.

Python | Tkinter | Backtracking | MRV | Algorithms | Unit Testing | GUI

GitHub →

Fish'n Weather

A full-stack weather and fishing application built with Java and Spring Boot. The application combines weather, astronomical, and mapping data to provide fishing conditions for a selected location.

Implemented interactive maps with Leaflet, integrated external APIs for weather and location data, and developed a fishing condition rating based on environmental factors.

Deployed as a containerized Spring Boot application using Docker and hosted on Render.

Java | Spring Boot | JavaScript | Thymeleaf | Leaflet | HTML | CSS | REST APIs | Docker
